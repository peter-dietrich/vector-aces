# Aircraft artwork provenance (current)

Vector Aces no longer loads aircraft photographs in the hangar. As of **2026.11.15 (build 3)**, every hangar hero panel is a procedurally drawn, original sepia engineering plate in `Sources/VectorAcesApp.swift`, showing distinct side elevation, planform, and front elevation plus a small in-game vector schematic.

No third-party photograph assets or internet access are needed for the hangar. The former remote Wikimedia Commons image links were removed from the presentation. Retain the historic photograph references below as archival notes only; they are **not used by the current application**.

The Vector Aces hangar uses public-domain historical aviation photographs. Images are displayed from Wikimedia Commons when an internet connection is available; the original, local vector aircraft schematic appears if an image cannot be loaded.

Before an offline signed release, bundle these four appropriately sized public-domain images locally and preserve these source notices.
