# Aircraft photograph credits

The Vector Aces hangar uses public-domain historical aviation photographs. Images are displayed from Wikimedia Commons when an internet connection is available; the original, local vector aircraft schematic appears if an image cannot be loaded.

| Aircraft | Historical image | Source/licensing |
|---|---|---|
| P-51D Mustang | North American P-51D Mustang USAF | [Wikimedia Commons — USAF Museum, public domain](https://commons.wikimedia.org/wiki/File:North_American_P-51D_Mustang_USAF.jpg) |
| P-47 Thunderbolt | Republic P-47N Thunderbolt in flight | [Wikimedia Commons — U.S. Air Force, public domain](https://commons.wikimedia.org/wiki/File:Republic_P-47N_Thunderbolt_in_flight.jpg) |
| P-38 Lightning | Lockheed P-38 Lightning USAF | [Wikimedia Commons — USAF Museum Photo Archive, public domain](https://commons.wikimedia.org/wiki/File:Lockheed_P-38_Lightning_USAF.JPG) |
| P-40 Warhawk | Curtiss P-40E Warhawk USAF | [Wikimedia Commons — USAF Museum, public domain](https://commons.wikimedia.org/wiki/File:Curtiss_P-40E_Warhawk_USAF.jpg) |

The plane selection UI distinguishes historical photography from the game's original vector flight artwork. External hosting means images require network access to load initially. Before an offline signed release, bundle these four appropriately sized public-domain images locally and preserve these source notices.
