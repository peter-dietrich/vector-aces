# Vector Aces — macOS Help

WWII-inspired arcade dogfighting

## How to play

Choose a P-51, P-47, P-38 or P-40 from the hangar. Survive aerial combat waves while monitoring your aircraft's damage, heading and radar.

## Keyboard and mouse controls

| Control | Action |
|---|---|
| Left / Right or A / D | Turn aircraft. |
| Up or W | Accelerate. |
| Down or S | Brake. |
| Space | Fire. |
| P | Pause or resume. |
| Return | Restart after a mission ends. |
| Escape | Return to the hangar. |

## Scores, saves and settings

Personal-best scoring is saved locally in newer builds. The game does not currently provide a general Save Game / Load Game workflow, and previous in-flight progress is not guaranteed to persist.

## Application menus

The native **Game** menu offers How to Play, Controls & Shortcuts, and Scores & Saving. The **Help** menu opens these offline instructions. Standard macOS App, Edit, Window, and Quit commands remain provided by the operating system. In-game gameplay buttons and shortcuts are unchanged.
